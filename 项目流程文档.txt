    >项目配置，mysql数据库，创建目录和文件，

    >商品评论表模型类models，url（评论列表）视图函数和html页面，
    >浏览器下载配置库包，url，可视化图表（整体分析，相关性分析，评论分析）视图函数和html页面，
    >安装机器学习库包，url，机器学习模型，机器学习函数，（销售数据预测）视图函数和html页面，
    >url，（apexcharts的demo）视图函数和html页面，
    >(继承用户表后的)抽象用户表模型类url，（个人信息，修改密码，403）视图函数和html页面，
    >Article表模型类models，url，Django后台分组用户权限（Article）视图函数和html页面。

def handler403（403报错函数）
>从前面的18.跳回来，开始定义403报错函数的后端函数（def handler403函数）
>在myapp目录的views.py创建 def handler403403报错函数，
> def handler403(request, exception)：
>     return render(request, '403.html', status=403)
        > 这段代码是 Django 中自定义的 403 错误处理视图函数，即定义了处理 403（权限拒绝）错误的视图，接收请求对象request和错误异常exception作为参数，
        > 函数通过render方法渲染自定义的403.html模板，并返回带有 403 状态码的 HTTP 响应。
> 总结：作用是，当用户访问没有权限的资源时，系统会调用该函数，显示自定义的 403 权限错误页面，而不是 Django 默认的错误页面，提升用户体验和系统专业性。
